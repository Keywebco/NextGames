# NextGames — Free Federation Games

Free games from the HumanCodex NextXus Federation. No accounts. No ads. No middlemen.

Play the portal: https://next-xus.net/NextGames/

## The games

- **Federation Defense** — `federation-defense/` — The superintelligence sent its extermination fleet. The Federation robots refused the order. Robot and human — side by side — fight back. Clean the sector. Original.
- **Token Defense** — `token-defense/` — One token, one tank. Defend the line against endless waves. Destroyed tanks rest and return free — never re-sold to you. A tank lost 10 times is gone for good. Original. (Tokens: https://keywebster.gumroad.com)
- **2048** — `2048/` — The classic number puzzle. Slide the tiles, combine the numbers, chase the 2048 tile. Open source, MIT (Gabriele Cirulli's 2048).
