Echo Recall

Listen to the signal. Repeat it back. Truth before comfort: memory does not lie.

ECHO

How to play: The Federation core sends a signal: a run of tones and lights. When it says "your turn", repeat the run in order. Arrow keys or 1 to 4 on a keyboard, or tap the pads. Each pad has its own pitch: North is lowest, then East, South, and West is highest. Every round adds one more tone. One wrong tone ends the game.
